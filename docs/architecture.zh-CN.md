## 两条渲染路径

`Session` 加载有大小限制的源码缓冲区，保守划分写作单元。UTF-8 字节编辑尽量保留未受影响的单元 ID，不保存原始文件。每次修改都会安排后台编译；符合条件的段落还可走实时路径。

后台路径复制不可变快照，通过命令行加载未修改的上游捕获宏包，运行 LuaLaTeX，直到辅助文件稳定或达到轮次上限。产物包括逐页显示列表、PDF 和段落上下文。唯一映射的顶层源码单元可以进入实时候选。BibTeX/Biber 和白名单索引工具在输入变化时执行，缺失产物不能视作收敛。LuaLaTeX 预加载一次性常驻导言区供后续后台使用；XeLaTeX/pdfLaTeX 运行普通 PDF 编译。

实时路径保持另一个已加载导言区的 LuaLaTeX 进程。安装捕获的上下文后，先排版旧段落，与后台结果的字形、规则及位置进行比较。探针一致后才排版新段落。出错、状态泄漏、不支持的绘制、插入项、映射不明确或超时预算都回到后台路径。这是保守核验，并不证明任意 TeX 宏无副作用。


Lua 后台可用会话 PDF 选页缓存替代未变化的独立图片。扫描器按读取顺序跟随字面输入，计算前置命令/设置哈希，拒绝计数器、引用、外部文件及不安全依赖。捕获层核对字体/颜色/宽度和跳过结束行；不匹配键被隔离，错误结果不会作为最终版面安装。LuaTeX 仅提取所需页，无运行时 npm 依赖；缓存容量有上限，并保留四次未使用轮次。缓存绘图的显示列表仍需要匹配 PDF，普通导出不使用此优化。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `document.ts` | UTF-8 编辑、注释和逐字内容遮罩、平衡范围划分、导言区边界 |
| `display-list.ts` | 有边界校验的 RTDL v1 二进制解码；未知记录要求降级 |
| `process.ts` | LuaLaTeX 查找、支持文件、输入路径、参数数组执行和进程树 |
| `engine.ts` | 常驻 LuaLaTeX 驱动、串行请求和响应帧读取 |
| `session.ts` | 缓冲区快照、上下文和探针、源码/引擎/版面版本、导出和取消 |
| `tex-syntax.ts`、`preamble.ts`、`eligibility.ts` | 平衡源码分析、有效导言区和保守规则 |
| `auxiliary.ts`、`background-engine.ts` | 受控文献/索引命令、标签及常驻后台进程 |
| `cli.ts` | JSON 行协议、有界输出与背压 |
| `vendor/realtime-tex/tex/` | 未修改的上游 Lua/TeX 运行时及其测试和实验 |

编译请求使用上游的原始 UTF-8 长度帧；上下文/控制请求保留 JSON 行。POSIX 通过 stdin 写请求，Windows 使用二进制命名请求管道。响应沿用长度前缀二进制帧，通过 POSIX FIFO 或 Windows 命名管道交给 Node 流读取。单帧上限 32 MiB，非预期积压触发恢复，不再轮询响应文件。

快照遍历/复制和逐页文件读取使用异步 I/O，复制最多并发八项，缓冲区内容直接写入快照，不保存原文。页面行和段落序号使用索引，上下文组装分批让出事件循环。这些措施减少 Node 卡顿，但不保证 TeX 启动或任意宏的速度。

## 顺序与恢复

事件带有相应的源码、上下文、引擎和版面版本。工作期间源码或上下文已变化的实时结果会被丢弃。后台快照可能落后于当前输入，宿主需要保留更新的覆盖层，并标记临时位置。导言区变化会关闭旧引擎。后台失败保留上次可用版面并报告诊断。修正源码或补装依赖后，可用 `requestLayout()` 重试。

会话拥有 TeX 子进程，关闭时终止它们。宿主释放 PDF 和字体句柄后负责最终缓存清理。最近的快照和 PDF 有保留上限，实时引擎正在使用的快照保持固定。源码、快照、文件数量、深度、帧和进程时间均设有边界；这些资源限制不是操作系统沙箱。

## 导出与宿主绘制

导出在新快照中运行所选普通 TeX 引擎，不加载捕获钩子；索引命令钩子记录 imakeidx 的工具请求，供宿主调度。结果返回收敛状态；达到轮次上限或编译期间又有编辑时可能为 false。宿主也可沿用现有可信构建流程处理文献、索引和自定义命令。

显示列表包含字体文件、字形 ID 和 scaled-point 几何信息。宿主需要准确绘制，或回退到对应 PDF。本包不包含浏览器渲染器、SyncTeX、字体轮廓引擎、编辑器、VS Code 扩展或 Electron。定位和分发契约见[嵌入说明](embedding.zh-CN.md)。

0.1.9 从顶层平衡定义推断宏及安全内联/块环境，更新规则时重新分段并保留未变化单元的 ID。无法解析字体文件或 glyph ID 的字形不能标为精确，仍使用匹配 PDF。字体缓存默认由 TeX 安装管理，宿主可指定独立目录；快照和图片缓存仍属于会话。可选 Poppler 栅格对照不属于实时渲染器，见[验证工具](verification.zh-CN.md)。
