## 两条渲染路径

`Session` 加载有大小限制的源码缓冲区，保守划分写作单元。UTF-8 字节编辑尽量保留未受影响的单元 ID，不保存原始文件。每次修改都会安排后台编译；符合条件的段落还可走实时路径。

后台路径复制不可变快照，通过命令行加载未修改的上游捕获宏包，运行 LuaLaTeX，直到辅助文件稳定或达到轮次上限。产物包括逐页显示列表、PDF 和段落上下文。只有唯一映射的顶层段落才能进入实时路径。缺失参考文献或索引产物不能视作收敛；本包不会自动调用文献或索引程序。

实时路径保持另一个已加载导言区的 LuaLaTeX 进程。安装捕获的上下文后，先排版旧段落，与后台结果的字形、规则及位置进行比较。探针一致后才排版新段落。出错、状态泄漏、不支持的绘制、插入项、映射不明确或超时预算都回到后台路径。这是保守核验，并不证明任意 TeX 宏无副作用。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `document.ts` | UTF-8 编辑、注释和逐字内容遮罩、平衡范围划分、导言区边界 |
| `display-list.ts` | 有边界校验的 RTDL v1 二进制解码；未知记录要求降级 |
| `process.ts` | LuaLaTeX 查找、支持文件、输入路径、参数数组执行和进程树 |
| `engine.ts` | 常驻 LuaLaTeX 驱动、串行请求和响应帧读取 |
| `session.ts` | 缓冲区快照、上下文和探针、源码/引擎/版面版本、导出和取消 |
| `cli.ts` | JSON 行协议、有界输出与背压 |
| `vendor/realtime-tex/tex/` | 未修改的上游 Lua/TeX 运行时及其测试和实验 |

发给 Lua 的请求使用 stdin JSON 行。响应沿用上游长度前缀二进制帧，通过 POSIX FIFO 或 Windows 命名管道交给 Node 流读取，消除响应文件轮询及其每次请求的额外延迟。JSON 转义避免 Windows 文本模式 stdin 改写 UTF-8、CRLF 和控制字符。单帧上限 32 MiB；出现预期之外的积压响应时触发恢复。

## 顺序与恢复

事件带有相应的源码、上下文、引擎和版面版本。工作期间源码或上下文已变化的实时结果会被丢弃。后台快照可能落后于当前输入，宿主需要保留更新的覆盖层，并标记临时位置。导言区变化会关闭旧引擎。后台失败保留上次可用版面并报告诊断。修正源码或补装依赖后，可用 `requestLayout()` 重试。

会话拥有 TeX 子进程，关闭时终止它们。宿主释放 PDF 和字体句柄后负责最终缓存清理。最近的快照和 PDF 有保留上限，实时引擎正在使用的快照保持固定。源码、快照、文件数量、深度、帧和进程时间均设有边界；这些资源限制不是操作系统沙箱。

## 导出与宿主绘制

导出在新快照中运行普通 LuaLaTeX，不加载捕获钩子。结果返回收敛状态；达到轮次上限或编译期间又有编辑时可能为 false。宿主也可沿用现有可信构建流程处理文献、索引和自定义命令。

显示列表包含字体文件、字形 ID 和 scaled-point 几何信息。宿主需要准确绘制，或回退到对应 PDF。本包不包含浏览器渲染器、SyncTeX、字体轮廓引擎、编辑器、VS Code 扩展或 Electron。定位和分发契约见[嵌入说明](embedding.zh-CN.md)。
