# 固定上游能力对照

[English](upstream-parity.md)

验收基准为 realtime-tex **0.0.7**，提交 `fcff7a5c7f33a288ecf40db886843754c62bbdfd`。此表记录工程能力覆盖，不表示完整兼容。保留 Node API；Rust crate 和 C ABI 不在已确认范围内。

| 能力 | rtex-ts 0.1.9 | 证据与边界 |
| --- | --- | --- |
| 未保存缓冲区、字节编辑、稳定单元身份 | 已实现 | UTF-8、嵌套分组、注释/逐字内容、未完成输入和过期结果测试 |
| 段落/数学/标题/环境分段 | 已改写 | 平衡扫描与自定义单元环境；捕获映射不明确时仍走后台 |
| 适用规则、宏包词汇、自定义宏 | 部分移植 | 上游表、不透明参数、递归宏防护、设置/分组/上下文检查；新增裸/花括号宏名、无参数 def、数学算子及自定义环境检查；标题/文档类规则和复杂签名尚未完整移植 |
| 常驻实时引擎与旧源码验证 | 已实现 | 真实中文/数学/多文件测试；未经验证不发布覆盖层，超时和状态泄漏触发回退/重启 |
| 二进制传输与数学归属 | 已实现 | 有界 RTDL、原始编译帧、POSIX FIFO、Windows 二进制命名管道；归属 ID 由宿主提供 |
| 后台快照与预加载导言区 | 已实现 | 异步有界复制、不可变缓冲区、预热正文更新、暂停/恢复与清理测试 |
| 引用及辅助工具 | 已改写 | BibTeX/Biber 选择、签名重跑、标签、makeindex/命名 imakeidx、记录的白名单程序；其他工具配置仍需对应测试 |
| 图片缓存扫描、PDF 选页提取及缓存调度 | 已改写 | 读取顺序/定义哈希、状态/结束行检查、LuaTeX 选页提取、四次未使用轮次、256 项/64 MiB 上限；仍走 PDF 回退，无实时绘图或跨会话复用声明 |
| 普通 PDF 导出 | 已实现 | 独立快照、引擎选择、辅助文件收敛与临时清理 |
| CLI serve/doctor/export/verify/profile/dl2json | 已改写 | JSON 行/背压、实时单元探针、Node 内存/CPU 快照和二进制转换；verify 不验证整篇文档 |
| 上游 CLI 基准/文档生成/PDF 对照套件 | 部分完成 | 实时/后台/启动基准、可选 Poppler pdf-compare 与 verify --pdf；生成器、结构及 PDF 字形对照尚未移植 |
| Rust ABI/API 兼容 | 范围外 | 独立 Node API，无 Rust 程序和原生 npm 依赖 |
| XeLaTeX/pdfLaTeX | 新增 PDF 路径 | 完整 PDF 布局/导出，无 Lua 捕获、实时字形或数学归属元数据 |

0.1.7 的新管道、后台引擎、辅助工具和多引擎 PDF 已通过三平台 CI；0.1.8 图片缓存已通过单独 CI；0.1.9 修改需要新 CI。见[兼容性](compatibility.zh-CN.md)及[性能方法](performance.zh-CN.md)。
